# Calculator

A simple and interactive calculator built using HTML, CSS, and JavaScript.

## Features

* Addition (+)
* Subtraction (-)
* Multiplication (×)
* Division (÷)
* Clear (CLR) button
* Equals (=) button
* Performs calculations using JavaScript's `eval()` function
* Clean and user-friendly interface

## Technologies Used

* HTML
* CSS
* JavaScript

## How It Works

The calculator takes the expression entered through the buttons and uses JavaScript to evaluate the calculation and display the result.
